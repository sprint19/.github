## Free, open tools

We keep a set of privacy-first engineering utilities at **[tools.sprint19.com](https://tools.sprint19.com)**. Every tool runs entirely in your browser. Nothing is uploaded, stored, or tracked.

- **Email & DNS:** DKIM, SPF, and DMARC builders and inspectors, DNS TXT parsing, message-header analysis, EML viewing.
- **SSL & Certificates:** OpenSSL CSR and Let's Encrypt command builders, HSTS header generator.
- **Auth & Tokens:** JWT decoder, Basic Auth header generator, OAuth scope formatter.
- **HTTP & Headers:** CORS checker, header analyzer, CSP parser, webhook viewer.
- **Config & Data:** `.env`, Redis URL, JSON, YAML, and ICS parsers.

32 tools, no accounts, no backend. Machine-readable catalog at [tools.sprint19.com/llms.txt](https://tools.sprint19.com/llms.txt).
